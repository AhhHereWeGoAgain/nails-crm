# Nails CRM

Локальная CRM для мастера ногтевого сервиса. Календарь записей, канбан сделок, база клиентов, выручка, налоги и расходы в одном приложении. **Без облака и подписки.** Интерфейс в стиле Bitrix24: боковая навигация, лёгкие карточки и SVG-иконки.

## Возможности

- **Календарь:** нажатие на день открывает создание сделки с выбранной датой; в списке дня видны записи, время, сумма и стадия.
- **Сделки:** отдельная канбан-доска со стадиями «Запланировано», «В работе», «Завершено», «Отменено». Карточки можно перетаскивать мышью; на телефоне доступен выбор стадии в карточке. Создание и редактирование сделок — из канбана либо календаря.
- **Клиенты:** отдельная база с именем, телефоном, заметками, источником и историей посещений. Время записи указывается в клиентской сделке.
- **Источники:** «Авито (модель)», «Авито (маникюр)», «Телеграм», «Реклама», «По рекомендации». Можно добавлять в настройках или выбрать «Другое» при создании клиента. Используемый источник удалить нельзя.
- **Доход:** выбор клиента, суммы, налоговой ставки 0%, 4%, 6% или произвольной. Доход от незавершённых и отменённых сделок **не входит** в финансовый результат.
- **Расход:** статья расхода, сумма, комментарий. В аренде можно подставить последнюю сумму либо ввести новую. Статьи расходов добавляются и удаляются в настройках; используемые статьи защищены от удаления.
- **Финансы:** статистика месяца, годовые показатели и разбивка по месяцам/статьям. Расчёт чистого результата: `завершённая выручка − налоги − завершённые расходы`.
- **Данные:** локальное хранение, импорт и экспорт резервной копии JSON. Старые базы SQLite и JSON-копии без карточек клиентов или стадий автоматически совместимы с новой версией.

**Важно:** финансовые показатели — для внутреннего учёта, не налоговая декларация. Деньги хранятся в целых копейках; налог округляется для каждой сделки.

## Веб-версия (локально)

Требуется **Python 3.10+**, установка Python-библиотек не нужна.

```bash
git clone https://github.com/AhhHereWeGoAgain/nails-crm.git
cd nails-crm
python server.py
```

Откройте `http://127.0.0.1:8765`. На Windows можно запустить `run_web.bat`.

База данных SQLite находится в `~/.nails-crm/data.sqlite3` (в Windows — в каталоге пользователя). При обновлении программы сохранённые записи не удаляются.

### Просмотр с телефона в одной сети Wi-Fi

```bash
python server.py --host 0.0.0.0 --port 8765
```

Откройте на телефоне `http://IP_КОМПЬЮТЕРА:8765`. Подключения к одному серверу используют общую SQLite-базу. **Сервер без пароля и HTTPS: не открывайте порт в Интернет и используйте только доверенную локальную сеть.**

## Десктопная утилита

```bash
python -m pip install pywebview
python desktop/launcher.py
```

На Windows есть `run_desktop.bat`. Это отдельное окно с тем же интерфейсом и локальной SQLite. Готового `.exe` в репозитории нет.

## Android

Каталог `android/` содержит исходники Android Studio-проекта на Java/WebView. Android-приложение работает без Python-сервера и хранит данные **отдельно** во внутреннем `localStorage` приложения.

Для сборки нужны Android Studio, Android SDK, JDK 17 и Gradle 8.9. В репозитории нет готового APK и `gradle-wrapper.jar`. Если требуется, создайте wrapper (`gradle wrapper --gradle-version 8.9`) и собирайте проект через Android Studio. APK на реальном телефоне в текущей среде не проверялся.

**Синхронизации** между автономным Android-приложением и десктопной SQLite пока нет. Данные можно перенести через **Настройки → Скачать JSON / Загрузить JSON**.

## Безопасность и резервные копии

- Не публикуйте базы SQLite, JSON-резервные копии и персональные данные клиентов в GitHub.
- JSON-копия содержит имена, телефоны и финансовую информацию — храните её в защищённом месте.
- При импорте JSON текущие данные **полностью заменяются**. Перед импортом сделайте резервную копию.
- Для приложения пока нет учётных записей, паролей, разграничения прав и шифрования базы. Не публикуйте его локальный HTTP-сервер в Интернет.

## Тестирование

```bash
python -m unittest discover -s tests -v
node tests/core.test.js
```

Дополнительный UI smoke test: `python tests/ui_smoke.py` (требуется Playwright и браузер Chromium). Тесты покрывают перенос старых данных, операции с клиентами, источниками, стадиями сделок и финансовые вычисления.

## Технологии

Python `http.server` + SQLite, HTML/CSS/Vanilla JavaScript с SVG-иконками, десктоп через `pywebview`, Android через WebView. Один веб-интерфейс используется во всех трёх вариантах.
